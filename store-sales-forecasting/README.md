# Store Sales Forecasting Dashboard

An advanced Machine Learning and Time Series Forecasting project focused on analyzing historical retail sales data and generating predictive sales forecasts through interactive analytics and intelligent forecasting models.

This project combines data preprocessing, feature engineering, machine learning, visualization, and dashboard development to simulate a real-world retail forecasting solution.

---

## Project Overview

The objective of this project is to:

- Analyze historical sales performance
- Identify seasonal and transactional sales patterns
- Build forecasting models for future sales prediction
- Compare machine learning algorithms
- Develop an interactive analytics dashboard using Streamlit

## Machine Learning Models

The following models were explored and evaluated:

| Model | Purpose |
|------|------|
| Linear Regression | Baseline forecasting |
| Random Forest Regressor | Nonlinear pattern learning |
| XGBoost Regressor | Advanced ensemble forecasting |

---

## Key Insights

- Lag-based features significantly improved forecasting accuracy.
- Ensemble models captured nonlinear sales patterns effectively.
- Seasonal and transactional variables strongly influenced future sales trends.
- XGBoost demonstrated strong predictive performance for structured retail forecasting tasks.
